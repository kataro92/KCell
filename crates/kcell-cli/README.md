# kcell-cli

CLI for [KCell](https://github.com/kataro92/KCell) — validate, specialize, run, and serve Cells / AI-men.

Installs the `kcell` binary:

```bash
cargo install kcell-cli
kcell --help
```

(The package name is `kcell-cli` because `kcell` is already taken on crates.io.)

Optional features: `wasi`, `notify`.

Repo: https://github.com/kataro92/KCell
