# Adapters

Optional bridges **outside** core. Start `kcell serve` first.

| Adapter | Role |
|---------|------|
| `kcell-mcp` | MCP tools over stdio |
| `kcell-agui` | AG-UI HTTP + SSE |
| `kcell-a2a` | A2A Agent Card + JSON-RPC |

See [adapters/](https://github.com/kataro92/KCell/tree/main/adapters).
