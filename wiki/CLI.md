# CLI

| Command | Purpose |
|---------|---------|
| `kcell validate` | Check manifests |
| `kcell specialize` / `new` | Create a Cell from the Stem |
| `kcell build` | Package digest |
| `kcell run` | Activate an AI-man |
| `kcell serve` | Keep Host alive (Unix socket) |
| `kcell call` | Talk to a running Host |
| `kcell discover` | List providers |

Control protocol: [docs/control-socket.md](https://github.com/kataro92/KCell/blob/main/docs/control-socket.md)
